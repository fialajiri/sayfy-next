# Sayfyho Memorial — www.sayfy.cz

Website of the Sayfyho Memorial MTB race. Frontend and backend live in one Next.js 16 app. It
replaces `sayfy-backend-ts` (Express) and `sayfy-frontend-ts` (Next 12).

```bash
cp .env.example .env.local   # Phase 0 needs nothing filled in
npm install
npm run dev                  # http://localhost:3000
```

Docs and plan: [`docs/`](docs/). Start with `docs/07-roadmap.md`. Agent guidance: `CLAUDE.md`.
