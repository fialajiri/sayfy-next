**Versions checked against the npm registry on 2026-10-05** (`npm view <pkg> version`, latest

## Native browser APIs instead of libraries

Following the global "prefer native APIs" rule, these legacy dependencies are replaced by the platform:

| Need | Native solution | Drops |
|---|---|---|
| News carousel on home, Sayfy photo strip | CSS **scroll-snap** + `scrollBy()` buttons | `react-alice-carousel` |
| Mobile menu, dialogs | Base UI Dialog/Sheet (shadcn) — `<dialog>` semantics, focus trap | `side-drawer`, `backdrop`, portal hooks in `_document` |
| Header turns solid when hero scrolls away | `IntersectionObserver` on a sentinel (or CSS scroll-driven animation where supported) | — |
| Course-profile line "draws" as you scroll | CSS `animation-timeline: view()` inside `@supports`, static fallback | — |
| Page transitions | View Transitions (React `<ViewTransition>` / Next `experimental.viewTransition`) — progressive enhancement, verify flag status in Phase 6 | `react-transition-group` |
| Image resize before upload | `createImageBitmap({ imageOrientation: 'from-image' })` + `OffscreenCanvas` / canvas (zive's `image-compression.ts`) | — |
| Share a news article | Web Share API with copy-link fallback (`navigator.clipboard`) | — |
| IDs for S3 keys | `crypto.randomUUID()` | `uuid` |

## Dependencies dropped

Backend: `express`, `express-async-errors`, `express-validator`, `cors`, `cookie-parser`,
`jsonwebtoken`, `aws-sdk@2`, `uuid`, `winston` + the custom Mongo transport (request logging to the
`logs` collection — replaced by Vercel logs; see `03` §Security), `nodemon`, `ts-node`, `jest`,
`ts-jest`, `supertest`, `@types/mongoose` (types ship with Mongoose).

Frontend: `axios`, `sass`, `phosphor-react`, `react-alice-carousel`, `react-transition-group`,
`msw` (no client HTTP layer to mock any more), `jest`, `jest-environment-jsdom`, and the stray
`r@0.0.5` package (accidental install — nothing imports it).

## Choices considered and rejected

- **Better Auth** (1.7.7) instead of Auth.js — the more active project, and the Auth.js team now
  works under it. Rejected *for this rewrite*: it brings its own `user`/`session`/`account`
  collections, so the 1–2 admin accounts would need migrating, and we'd lose code parity with zive.
  Revisit if both apps ever move together.
- **Embla carousel / Motion** — not needed. Scroll-snap and CSS do the job, so no animation runtime
  ships to every visitor.
- **isomorphic-dompurify** — needs jsdom on the server. `sanitize-html` is lighter and zive already
  uses it.
- **Postgres / Prisma** — see `05-data-and-auth-migration.md`. Keep Mongo.
- **Vercel Blob** instead of S3 — would mean migrating every existing image URL. Keep the
  `sayfyho-memorial` bucket.
